# Retail Sales Analysis and Prediction

## Project Overview
This project analyzes retail sales data and predicts sales
using Python and Machine Learning.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Regression

## Project Workflow
1. Data loading and exploration
2. Data cleaning
3. Exploratory Data Analysis
4. Data visualization
5. Feature engineering
6. Model training
7. Model evaluation
8. Sales prediction

## Project Files
- Retail_Sales_Analysis.ipynb
- retail_sales_cleaned.csv
- Retail_Sales_Analysis_Report.txt
- retail_sales_model.pkl
- sales_prediction_results.csv
- README.md

## Conclusion
This project explores retail sales trends and uses machine
learning to estimate sales based on selected order features.
